Sovrium pages

Builds, tags, exports and checks the pages of a Sovrium bundle. It never changes a layer you drew, and it talks to nothing: no Sovrium instance, no network.

Import a page

First import the bundle's adapters/figma/*.tokens.json with Figma's own Variables import. Then pick a page from adapters/figma/pages/.

Export

Writes each Sovrium page on this Figma page back as its .figma.json.

Check

Lists the values off the spacing scale, with the nearest token, and the layers that are no kit component. Select them to fix them yourself.
